## Overview 

This course brings together students from different disciplines, with varying experience of programming and mathematics. It aims to help you make well-informed choices when developing research software. Some topics may therefore take a more computer science oriented approach than you have encountered before.

The following pages are intended to lay out the expectations that we have for students on this course. These pages will not contain all of the basics of programming from first steps - we do expect you to come in with prior programming experience - but address some of the most common problems and clarifies the expectations for exams. In this section (and this section only) we will give all examples in both C++ and Python. (You will notice that the examples are usually almost identical except that C++ requires you to write your types more explicitly, and there is some extra punctuation!)

- [Preliminary Mathematics](./preliminaryMathematics.md): this page will list the mathematics that we expect you to understand by the time you come to the exam. Note that most of these are focussed on understanding broad concepts and mathematical notations; there is not an expectation to be able to do complex mathematics beyond what is required for the analysis of algorithms section of the course. This mathematical background is vital for being able to understand problem descriptions.
- [Basic Types](./basicTypes.md): this page gives an overview of some of the most common data types used in programming, giving their C++ versions. You should be familiar with their equivalents already in at least one programming language. 
- [Data Representation](./dataRepresentation.md): this page gives a preliminary overview of translating concepts into data that can be stored on a computer. This is generally assumed as a pre-requisite to the course as a foundation of programming technique, but some students may not have had to write their own data representations before so it is imperative that you understand how to do this. Writing data structures will be necessary for all forms of assessment.
- [Function Representation](./functionRepresentation.md): this is a special case of data representation where the object that we want to represent is some kind of function. There are a number of nuances based on the different kinds of functions we might talk about, and we expect some of the examples of function representation to be new to most students, so please make sure you are familiar with each of them.
